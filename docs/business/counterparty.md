# Контрагент
## Назначение
Региональный дилер. 
## Связи
Контрагент может иметь:
1. склады выгрузки в регионе (Хабы);
2. сотрудники (пользователи), закрепленные за контрагентом и складом (Хабом);
3. закрепленные организации для оформления заказов по ф-1, для заказов по ф-2 используется только имя контрагента;
4. товары, доступные к заказу (только отмеченные в профиле товары попадают в форму заказа);
5. типы оплат, устанавливаются контрагенту для высталвения реквизитов и контроля оплат;
6. реквизиты, актуальные разовые и/или (Осама).
## Режимы выставления реквизитов
TARGET_ONLY - разовые. Доступны только целевые реквизиты.
WEEKLY_ONLY - Осама.Доступны только реквизиты Осама. Требуется указание недельного лимита.
BOTH - Доступны оба типа реквизитов. Требуется указание недельного лимита.
## Изменение недельного лимита
Новый (измененный) лимит применяется только к новым (будущим) реквизитам Осама.
Изменение лимита не влияет на ранее созданные и текущие реквизиты.
