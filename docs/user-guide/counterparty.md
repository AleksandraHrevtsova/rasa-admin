# Контрагент
## Работа с контрагентами
### Список контрагентов
Раздел находится во вкладке меню: Контрагенты.

#### Доступны режимы:
* Активные
* Неактивные

Активация/деактивация возможна из списка по клику на кнопку в конце строки (также на странице редактирования).

#### Поиск осуществляется по:
* полному названию
* публичному названию

#### Действия
* Создать
* Редактировать
* Активировать
* Деактивировать

### Создание контрагента
Поле                      | Редактирование | Описание
--------------------------|:--------------:|----------------
Полное название           |        ДА      |Как в 1С
Публичное название        |        ДА      |Может отличаться от полного
Доступные типы реквизитов |        ДА      |Осама, Разовые или Все 
Лимит оплат Осама         |        ДА      |Устанавливается для Осама и Все
Доступные типы оплат      |        ДА      |Для реквизитов и контроля оплат
Доступные товары          |        ДА      |Для отображения в заказах
Сотрудники                |       НЕТ      |Только просмотр, создание и закрепление на странице пользователя
Склады                    |       НЕТ      |Только просмотр, создание и закрепление на странице склада
Организации               |       НЕТ      |Только просмотр, создание и закрепление на странице организации

### Правила
1. Контрагент не может самостоятельно создавать хабы. Хаб создается в разделе "Хабы" и закрепляется за контрагентом.
2. Сотрудник всегда принадлежит одному контрагенту.
3. Платежные организации не привязываются к контрагенту напрямую. Они используются системой для формирования реквизитов на оплату.
4. На странице контрагента отображаются только актуальные реквизиты.
История реквизитов доступна в разделе "Реквизиты".
5. Изменение недельного лимита не изменяет лимиты ранее выданных реквизитов. Для каждого изменения создается новая версия настройки с указанием периода действия.
